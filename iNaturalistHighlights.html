Set up
Back up to iCloud, OneDrive, Google Drive, Dropbox, Box or another cloud
  • Computer, Chrome or Edge (automatic): install your cloud's desktop app (iCloud for Windows, OneDrive, Google Drive for desktop, Dropbox or Box Drive). Then click Link auto-save file… and save the file inside that cloud folder. Every change is written to it and the cloud app syncs it. On another computer, use Import from file and pick it from the same folder.
  • Computer, any browser: Export to file opens a Save dialog in Chrome and Edge, so you can pick your cloud folder directly. Other browsers save to Downloads; move the file into your cloud folder.
  • iPhone and iPad: Share… → Save to Files → iCloud Drive (or OneDrive, Google Drive, Dropbox or Box, if their apps are installed). To restore, Import from file → Browse → the same place.
  • Android: Share… → Drive, OneDrive, Dropbox or Box. To restore, Import from file and pick the file from that app in the file picker.
Sharing options: choose users and places, add your name and a note
Data from the public iNaturalist API. Each of the user's sightings that could be a county, state, country or world first is automatically checked against all of iNaturalist's data for that place (not just this user's history), and the Firsts tabs list only the ones confirmed as the earliest record of that species in that place by anyone. Checks run quietly in the background after load, throttled to be polite to the API, and results are cached permanently in this browser's IndexedDB so they never need to be re-checked. Observations are cached the same way, so reloading the same user is instant. "Refresh" only downloads observations added or edited since the last sync (a diff, not a full redownload); use "Full Resync" if you want to clear the cache and start over (e.g. to pick up observations deleted upstream). Searching by place works the same way: its species list is cached locally, and "who found it first" per species is looked up lazily (only for whichever page of the Species Records tab you're viewing) and cached permanently, so a species is never looked up twice. "Refresh" re-fetches the species list but keeps those cached first-found lookups; "Full Resync" clears everything for that place. "Download report" saves what's loaded for a user or place as a standalone page you can share or print to PDF, and "Download spreadsheet" saves the same rows as a CSV. For a place, "Top Observers" ranks who has the most observations or species there, and "Compare Observers" sets two people's species lists for that place side by side (only one, both, or neither yet), with a CSV download. Because browser storage can be wiped, "Export to file" saves the cache as a compact .zip backup file (all of it, or just the users and places you pick) and "Import from file" loads one back, merging with whatever is already cached; older .json and .json.gz backups still import. In Chrome/Edge you can also link an auto-save file that is rewritten with the full cache about 15 seconds after it changes. Backups can also go to the cloud: OneDrive, Google Drive and Dropbox connect directly after a one-time setup guide in the backup panel (the setup is kept in this browser and travels inside backup files), and iCloud, Box and any other service work through their synced folders or the phone share sheet.
